# QR2Finance 🚀

Telegram-бот для автоматического учета расходов по QR-чекам.

## Как это работает?
1. 📸 Сканируете QR-код с чека в приложении ФНС
2. 📱 Отправляете JSON в нашего Telegram-бота
3. 📊 Получаете автоматическую категоризацию и статистику

## Технологии
- Python + aiogram
- PostgreSQL + Redis
- API ФНС России
- Podman | Docker для контейнеризации
